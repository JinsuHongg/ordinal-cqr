# OCQR Theory

**Status:** Draft normative theory
**Method:** Ordinal Conformalized Quantile Regression (OCQR)
**Version:** 0.3.0

---

## 1. Setup

Let

\[
(X,Z,Y)
\]

be an observation, where \(X\in\mathcal X\), \(Z\in\mathbb R\), and

\[
Y\in\mathcal Y=\{0,\ldots,K-1\}.
\]

Let

\[
-\infty=b_0<b_1<\cdots<b_K=+\infty
\]

and define

\[
B_k=[b_k,b_{k+1}).
\]

Assume target-label consistency:

\[
Y=k\Longrightarrow Z\in B_k.
\tag{1}
\]

For class-only datasets, \(Z\) may be a fixed surrogate embedding. The theorem is valid for the declared embedding, but efficiency and set membership need not be invariant under arbitrary monotone recodings.

---

## 2. Frozen quantile procedure

Let \(\widehat q_L(x)\) and \(\widehat q_U(x)\) be two fitted quantile predictors. Canonical experiments use levels \(\alpha/2\) and \(1-\alpha/2\), but the validity argument below does not depend on those exact levels.

Define crossing-corrected endpoints

\[
\widehat\ell(x)=\min\{\widehat q_L(x),\widehat q_U(x)\},
\qquad
\widehat u(x)=\max\{\widehat q_L(x),\widehat q_U(x)\}.
\]

Let \(\mathcal F\) denote the sigma-field generated by all information used to construct the fitted prediction procedure before conformal calibration. It includes:

- the training and validation observations;
- the fitted model parameters and selected checkpoint;
- target transformations and bins;
- base quantile levels and the nonconformity score;
- hyperparameters and method-variant selection;
- the fixed Mondrian taxonomy;
- fallback and hull policies.

All components in \(\mathcal F\) must be selected without using calibration or test observations. Calibration observations enter only through the prespecified calculation of \(q_k\). Test observations remain untouched until final evaluation.

Unless explicitly stated otherwise, the finite-sample validity statements below are conditional on \(\mathcal F\). Marginal label-conditional coverage follows by averaging the conditional bound over \(\mathcal F\). All statements assume \(Z\), \(\widehat\ell(X)\), and \(\widehat u(X)\) are finite real values. Nonfinite model outputs are outside the method definition and must raise an implementation error.

---

## 3. Nonconformity score and inversion

Define

\[
s(x,z)=\max\{\widehat\ell(x)-z,\;z-\widehat u(x)\}.
\tag{2}
\]

Negative scores are allowed.

For finite \(q\), define

\[
A_q(x)=\{z:s(x,z)\le q\}.
\tag{3}
\]

For \(q=+\infty\), define \(A_q(x)=\mathbb R\).

### Proposition 1: exact score inversion

For \(z,\widehat\ell(x),\widehat u(x)\in\mathbb R\) and \(q\in\mathbb R\cup\{+\infty\}\),

\[
z\in A_q(x)\Longleftrightarrow s(x,z)\le q.
\tag{4}
\]

For finite \(q\),

\[
A_q(x)=
\begin{cases}
[\widehat\ell(x)-q,\widehat u(x)+q],
&\widehat\ell(x)-q\le\widehat u(x)+q,\\[4pt]
\varnothing,&\text{otherwise.}
\end{cases}
\tag{5}
\]

#### Proof

The inequality \(s(x,z)\le q\) is equivalent to the pair

\[
\widehat\ell(x)-z\le q,
\qquad
z-\widehat u(x)\le q,
\]

which rearranges to (5). The \(+\infty\) case is immediate for finite scores. \(\square\)

## 4. True-label Mondrian calibration

Let the calibration sample be

\[
\{(X_i,Z_i,Y_i)\}_{i=1}^{n}.
\]

For class \(k\), define the random calibration count

\[
N_k=\sum_{i=1}^{n}\mathbf 1\{Y_i=k\}
\]

and the class score multiset

\[
\mathcal S_k=\{s(X_i,Z_i):Y_i=k\}.
\]

Define

\[
r_k=\left\lceil(N_k+1)(1-\alpha)\right\rceil.
\tag{6}
\]

Augment the multiset with \(+\infty\):

\[
\widetilde{\mathcal S}_k=\mathcal S_k\cup\{+\infty\}.
\]

Let \(\widetilde S_{k,(j)}\) be its \(j\)-th order statistic, retaining ties. Define

\[
q_k=\widetilde S_{k,(r_k)}.
\tag{7}
\]

This gives \(q_k=+\infty\) whenever no finite calibration order statistic supports the requested rank.

## 5. Candidate membership and post-processing

For candidate class \(k\), define

\[
I_k(x)=A_{q_k}(x).
\]

Define

\[
C_{\mathrm{raw}}(x)
=
\{k:I_k(x)\cap B_k\neq\varnothing\}.
\tag{8}
\]

Define the conservative nonempty fallback

\[
\widetilde C_{\mathrm{raw}}(x)=
\begin{cases}
C_{\mathrm{raw}}(x),&C_{\mathrm{raw}}(x)\neq\varnothing,\\[4pt]
\mathcal Y,&C_{\mathrm{raw}}(x)=\varnothing.
\end{cases}
\tag{9}
\]

For nonempty \(A\subseteq\mathcal Y\), define

\[
\operatorname{Hull}(A)
=
\{j:\min A\le j\le\max A\}.
\tag{10}
\]

The final prediction set is

\[
C(x)=\operatorname{Hull}(\widetilde C_{\mathrm{raw}}(x)).
\tag{11}
\]

---

## 6. Exchangeability assumption

For class \(k\), define the fixed label-based calibration index set

\[
\mathcal I_k=\{i:Y_i=k\},
\qquad
N_k=|\mathcal I_k|.
\]

Fix \(k\) and condition on \(\mathcal F\), the event \(N_k=m\), and \(Y_{n+1}=k\). Assume that the scores indexed by \(\mathcal I_k\), together with the test score, are exchangeable under this conditioning.

The Mondrian taxonomy and label rule are fixed elements of \(\mathcal F\); class membership is not adaptively selected from the realized calibration scores.

The guarantee is **not** conditional on the realized numerical calibration scores themselves.

---

## 7. Lemma 1: class-specific split-conformal validity

### Statement

Under the assumption in Section 6, for almost every realization of \(\mathcal F\),

\[
\Pr\{s(X_{n+1},Z_{n+1})\le q_k\mid \mathcal F,Y_{n+1}=k\}
\ge1-\alpha.
\tag{12}
\]

Equivalently,

\[
\Pr\{Z_{n+1}\in I_k(X_{n+1})\mid \mathcal F,Y_{n+1}=k\}
\ge1-\alpha.
\tag{13}
\]

### Proof

First condition on \(\mathcal F\), \(N_k=m\), and \(Y_{n+1}=k\). Let the resulting calibration scores be

\[
S_1,\ldots,S_m
\]

and let \(S_{m+1}\) be the test score. By assumption, these \(m+1\) scores are exchangeable.

Set

\[
r=\lceil(m+1)(1-\alpha)\rceil.
\]

Let \(q\) be the \(r\)-th order statistic of

\[
\{S_1,\ldots,S_m,+\infty\}.
\]

By the standard exchangeable-rank argument with non-strict inclusion, ties can only increase coverage, so

\[
\Pr\{S_{m+1}\le q\mid \mathcal F,N_k=m,Y_{n+1}=k\}
\ge \frac{r}{m+1}
\ge1-\alpha.
\tag{14}
\]

This includes \(m=0\) and unattainable finite ranks, for which \(q=+\infty\) and the conditional probability is one.

Finally, average (14) over the conditional distribution of \(N_k\) given \(\mathcal F\) and \(Y_{n+1}=k\). This yields (12) for almost every realization of \(\mathcal F\). Proposition 1 gives (13). \(\square\)

### Remark

When \(q_k=+\infty\), class \(k\) has coverage one before post-processing. What is lost is informative finite width and efficiency, not coverage validity.

## 8. Lemma 2: numeric-target inclusion implies true-bin inclusion

### Statement

If \(Y=k\Longrightarrow Z\in B_k\), then

\[
Z\in I_k(X),\;Y=k
\Longrightarrow
k\in C_{\mathrm{raw}}(X).
\tag{15}
\]

### Proof

On \(Y=k\), consistency gives \(Z\in B_k\). If also \(Z\in I_k(X)\), then

\[
Z\in I_k(X)\cap B_k,
\]

so the intersection is nonempty and candidate \(k\) belongs to the raw set. \(\square\)

### Remark

The reverse implication need not hold. A candidate bin can intersect the numeric acceptance set even when the particular true numeric target is not inside it. Hence ordinal-bin coverage can be conservative relative to continuous-target coverage.

---

## 9. Lemma 3: fallback and hull preserve coverage and guarantee contiguity

### Statement

For every \(x\),

\[
C_{\mathrm{raw}}(x)
\subseteq
\widetilde C_{\mathrm{raw}}(x)
\subseteq
C(x).
\tag{16}
\]

Moreover, \(C(x)\) is nonempty and ordinally contiguous.

### Proof

If \(C_{\mathrm{raw}}(x)\neq\varnothing\), the first inclusion is equality. If it is empty, it is a subset of \(\mathcal Y\), so the first inclusion still holds.

The hull of a nonempty set contains that set, proving the second inclusion. Both \(\widetilde C_{\mathrm{raw}}(x)\) branches are nonempty, and the hull contains every ordinal index between its minimum and maximum, proving nonemptiness and contiguity. \(\square\)

## 10. Main theorem: class-conditional ordinal coverage

### Theorem

Fix \(k\in\mathcal Y\). Assume:

1. \(\mathcal F\) is constructed using only training/validation data independent of calibration and test data;
2. the conditional exchangeability assumption in Section 6 holds;
3. target-label consistency (1) holds;
4. Mondrian groups use the supplied true label;
5. \(q_k\) is the exact augmented order statistic (7);
6. candidate \(k\) is evaluated using \(q_k\);
7. membership follows (8);
8. fallback and hull follow (9)–(11).

Then, for almost every realization of \(\mathcal F\),

\[
\Pr\{Y_{n+1}\in C(X_{n+1})\mid \mathcal F,Y_{n+1}=k\}
\ge1-\alpha.
\tag{17}
\]

### Proof

Conditional on \(\mathcal F\), Lemma 1 gives numeric-target inclusion with probability at least \(1-\alpha\). Lemma 2 maps that event to inclusion of the true class in \(C_{\mathrm{raw}}\). Lemma 3 shows that fallback and hull only add labels. Therefore the true class remains in the final set with probability at least \(1-\alpha\). \(\square\)

### Corollary: marginal label-conditional coverage

Averaging (17) over the conditional distribution of \(\mathcal F\) given \(Y_{n+1}=k\) gives

\[
\Pr\{Y_{n+1}\in C(X_{n+1})\mid Y_{n+1}=k\}
\ge1-\alpha.
\tag{18}
\]

The guarantee in (17) is conditional on the fitted training/validation procedure \(\mathcal F\), but not on the realized numerical calibration scores. Equation (18) is the corresponding label-conditional guarantee after averaging over the randomness in \(\mathcal F\).

## 11. Dataset interpretation

### 11.1 Class-only datasets

For RetinaMNIST and EyePACS, the canonical embedding is \(Z=Y\) with fixed midpoint bins. The theorem applies to that representation. Different monotone embeddings can alter fitted intervals, bin intersections, and efficiency and therefore constitute different method variants.

### 11.2 UTKFace

For UTKFace, \(Z\) is age and \(Y\) is the fixed age-bin label. The dataset contract must establish the bin partition and boundary convention.

### 11.3 Solar flare

For solar-flare data, \(Z\) is peak X-ray flux or its fixed transformation and \(Y\) is the supplied flare class. A dataset contract and reproducible validation artifact must verify their target-label-bin consistency before canonical experiments. Calibration grouping uses the supplied class label, while the numeric flux is used in the score.

The 2010–2019 temporal-window development splits and 2020–2024 future holdout prevent direct test leakage but do not establish exchangeability. The solar experiment is therefore an evaluation under the theorem's exchangeability assumption and an empirical temporal-extrapolation study. Repeated active-region dependence must be analyzed separately.

## 12. Required empirical validation

Implementation validation must include:

- score-inversion tests;
- integer-target/floating-threshold bin tests;
- true-label grouping tests;
- random-\(N_k\) synthetic coverage tests;
- nonfinite endpoint rejection;
- \(+\infty\) correction tests;
- empty-raw-set full fallback tests;
- hull inclusion and contiguity tests;
- raw-empty, fallback-inflation, hull-inflation, and full-set metrics;
- per-class calibration metadata and provenance.

---

## 13. Defensible manuscript claim

> Under conditional within-class exchangeability, a fixed target-to-bin representation, exact true-label Mondrian split-conformal calibration, candidate-specific score inversion, and add-only fallback and hull post-processing, OCQR provides finite-sample class-conditional ordinal coverage. The full-set empty-set fallback guarantees nonempty contiguous outputs, while potentially reducing efficiency.


## 14. Implementation status

Version 0.3 is the target theoretical specification. It does not describe the current repository implementation as canonical until integer-safe binning, the separate \(Z,Y_{\mathrm{ord}}\) calibration interface, explicit nonfinite checks, synchronized configuration, and required metadata/metrics are implemented and tested.
